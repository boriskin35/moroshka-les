# МорошкаЛес — Официальный сайт

Сайт производителя быстровозводимых деревянных домов, бань и коммерческих зданий из кедра «МорошкаЛес».

## Стек технологий

- **Фреймворк:** [Astro](https://astro.build/) (v7)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/) (v4)
- **UI-компоненты:** [Preline UI](https://preline.co/)
- **Плавный скролл:** Lenis
- **Анимации:** GSAP
- **Хостинг:** Netlify

## Команды разработки

- `npm run dev` — запуск локального сервера разработки
- `npm run build` — проверка типов и сборка продакшен-версии
- `npm run preview` — предпросмотр собранной версии
